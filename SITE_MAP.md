## Content types

| Type | Lives in | Schema | URL pattern |
|---|---|---|---|
| essay | `src/content/essays/*.md` | `title, date, type, tags, readingMin, featured` | `/writing/[slug]` |
| letter | `src/content/letters/*.md` | `number, title, date` | `/writing/letters/[n]` |
| note (wood) | `src/content/notes/*.md` | `title, stage, lastWatered, tags, backlinks` | `/wood/[slug]` |
| book | `src/content/books/*.json` | `title, author, status, rating, note` | `/collections/books/[id]` |
| music | (in `books` collection extended, or separate) | `title, artist, status, why` | `/collections/listening/[id]` |
| link | (in `books` collection extended, or separate) | `title, domain, why, saved` | (single page, no detail) |

`type` for essay can be `essay | field | letter | project`.

## Relationships

- **essay ↔ note** — bidirectional backlinks (`note.backlinks: ['vibe-coding', ...]` references essay slugs OR other note ids)
- **note ↔ note** — same
- **essay → book** — cite (essay's `tags` can include book id, OR essay has explicit `cites: [bookId]`)
- **letter → essay** — letter `roundup: [essaySlug, ...]` aggregates that month's essays
- **tag** — cross-type, every entity can have tags

---

## URL conventions

- All lowercase
- kebab-case for slugs; Chinese OK (`/writing/vibe-coding-之后`)
- No date prefix (`/writing/2026/...` ❌)
- No file extensions
- Pluralize collection roots (`/essays`, `/books`)
- Tag root is `/tag/[name]` (singular), e.g. `/tag/vibe-coding`

When a slug changes: add a 301 redirect via `astro.config.mjs` redirects map. Slugs are permanent contracts.

## Frontmatter contract

Each piece of content has a stable contract. Adding a field: bump schema in `src/content/config.js` AND add it here.

### essay
```yaml
title:       string (required)
subtitle:    string
summary:     string  (used as lead + meta description)
date:        date    (required)
updated:     date
type:        essay | field | letter | project (default: essay)
tags:        [string]
readingMin:  number
featured:    boolean (default: false)
draft:       boolean (default: false)
cover:       string  (public-relative image path)
```

### note
```yaml
title:        string (required)
summary:      string
stage:        seedling | growing | evergreen (default: seedling)
created:      date (required)
lastWatered:  date (required)
tags:         [string]
backlinks:    [string]
draft:        boolean
```
