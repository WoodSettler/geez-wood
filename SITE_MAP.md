## Content types

| Type | Lives in | URL pattern |
|---|---|---|
| essay | `src/content/essays/*.md` | `/writing/[slug]` |
| book | `src/content/books/*.json` | `/collections` (标签 `书`) |
| listening | `src/content/listening/*.json` | `/collections` (标签 `专辑` / `单曲` / `播客`) |
| page copy | `src/content/pages/*.md` | 无独立 URL; 被 about / now / writing / collections 读取 |

`books` 与 `listening` 两个集合保留各自 schema (Keystatic 不用改), 在 `/collections` 合并成一个网格, 按加入日期倒序。

---

## URL conventions

- All lowercase
- kebab-case for slugs; Chinese OK (`/writing/一步顶一万步`)
- No date prefix, no file extensions

When a slug changes: add a 301 redirect via `astro.config.mjs` redirects map. Slugs are permanent contracts.

## Frontmatter contract

Adding a field: bump schema in `src/content/config.js` AND `keystatic.config.ts` AND add it here.

### essay
```yaml
title:       string (required)
subtitle:    string
summary:     string  (used as lead + meta description)
date:        date    (required)
updated:     date
type:        essay | field | letter | project (default: essay)
tags:        [string]   # 纯文本展示, 不再链接
readingMin:  number
featured:    boolean (default: false)
draft:       boolean (default: false)
cover:       string  (public-relative image path)
```

### book  (`src/content/books/*.json`)
```yaml
title, titleZh, author (required), year, status: reading|finished|paused|want,
rating, progress, note, coverTint: t|s|u|p|n, date
```

### listening  (`src/content/listening/*.json`)
```yaml
title:      string (required)
artist:     string (required)
year:       number
kind:       album | track | podcast (default: album)   # 决定 collections 上的标签
status:     loop | new | paused (default: new)
why:        string
cover:      string   # 真封面图, e.g. /covers/listening/xxx.jpg
coverTint:  t | s | u | p | n   # 无 cover 时的兜底色块
link:       string   # 点封面跳转的站内 URL
date:       date     # 加入日期, 用于排序
```

**封面约定:** 有 `cover` 用真图, 没有就用 `coverTint` 色块。真图路径必须是 Keystatic 的格式 `public/covers/listening/<条目文件名>/cover.jpg` (值写 `/covers/listening/<条目文件名>/cover.jpg`); 放在别处的话, 后台读不到图, 一保存就会把 `cover` 字段清掉。最省事的办法是直接在后台上传。
