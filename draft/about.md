| 标签                   | 视觉效果                                |
| -------------------- | ----------------------------------- |
| `<b>词</b>`           | 主墨色 + 加粗 (强调)                       |
| `<em>词</em>`         | 衬线斜体大字 (柔强调)                        |

| `<strong>词</strong>` | 600 字重                              |
| `<code>词</code>`     | 等宽 + 浅底色                            |
| `{SITE.name}`        | 从 `site.config.js` 自动注入 (现在 = Ting) |
| `{SITE.location}`    | 同上                                  |

## E · 正文段落 1 (首字下沉)

拥有自己的个人网站是一件奢侈的事情。至少，对大多数人来说，对一两年前的我来说，是这样的。倘若要恰当地介绍自己，我仍然不知该如何对我的现状进行身份归纳。vibe coder？vibe designer？我感觉我远远没达到那么远的地方。非要说的话，我需要一连串形容词，一个认真的、充满热情的、年轻的、废寝忘食的AI User。

## F · 正文段落 2

一切始于2023年。大约9月我知道了Chatgpt，并一路订阅至2026年。彼时我在广州，刚从北京辞职，从6月一直gap着，一直到24年2月重新上工。

在那几个月里我用GPT和Mid journey做了一些无聊有趣的事情。我想每天看一个全球任意城市，看城市面貌，听那个城市有关的音乐。于是用GPT每天抽城市、生成季节和时辰不同的多段提示词、去midjourney中生成图片、然后用GPT推荐的音乐，凑到一块发抖音。每天一个小时，坚持到我的midjourney被停用。

---

## G · 正文段落 3

另一个里程碑是去年的10月左右吧，我在网页的窗口中乐此不疲地复制粘贴，试图帮我自己开发一些自动化的工具。当时我既不懂context，也不懂IDE，在无限的本地试运行和请GPT老师诊断的复制粘贴中把窗口撑爆 ，但还是一次次喜不自胜地成功跑通了很多小小的不值一提的工具。直到最新里程碑，今年4月我开始使用了Claude，然后是Claude Code，嗯，everything changed.
