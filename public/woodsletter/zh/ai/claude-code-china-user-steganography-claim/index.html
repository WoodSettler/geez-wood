Claude Code 被指用隐写标记识别中国用户

公众号「数字生命卡兹克」转述 Reddit 逆向分析：Claude Code 读取时区与中转地址，并在系统提示词里用肉眼不可见的字符差异标记用户。

2026 年 7 月初，Claude 国内用户遭遇大面积封号。期间 Reddit 上有用户逆向 Claude Code，称发现一组隐蔽函数：它不看 IP，而是根据本地时区和 API 中转地址判断用户是否来自中国，再把结果藏进每次请求的系统提示词里。公众号作者称已在自己电脑上复现。

信息来源说明
以下机制均来自社区逆向分析与公众号作者自述，原文未提及 Anthropic 的官方回应，请结合后续报道判断。

据称的识别与标记机制

  1. 读取系统时区
    检查 macOS 或 Linux 的本地时区是否为 Asia/Shanghai 或 Asia/Urumqi，与网络出口 IP 无关。
  2. 检查中转地址
    取出 ANTHROPIC_BASE_URL 中的域名，与内置的 147 个域名比对；列表经 base64 编码后再做 XOR（密钥 91）混淆。
  3. 改写日期行
    把系统提示词 “Today's date is …” 中的单引号替换为三种外观相同的 Unicode 字符之一，并在时区命中时把日期中的连字符改成斜杠。
  4. 服务器端读取
    两处差异组成 2 到 3 比特的分类标记，服务器只需识别字符即可判断请求是否来自中国大陆时区。
