Claude Code accused of hiding a steganographic marker to flag users in China

A WeChat blogger relays a Reddit reverse-engineering claim: Claude Code reads the time zone and proxy URL, then tags requests with invisible character swaps in the system prompt.

2026-07-01 数字生命卡兹克mp.weixin.qq.com

In early July 2026, Claude users in China were hit by a wave of account bans. In the same week a Reddit user who reverse-engineered Claude Code said they had found a set of hidden functions. Rather than checking IP addresses, the code reportedly infers whether a user is in China from the local time zone and the API proxy address, then embeds the result in the system prompt of every request. The WeChat author says they reproduced the finding on their own machine.

About the sources
The mechanism below comes from community reverse engineering and the author's own account. The original article does not mention any official response from Anthropic; read it alongside later coverage.

How the marker reportedly works

  1. Read the system time zone
    Checks whether the local macOS or Linux time zone is Asia/Shanghai or Asia/Urumqi, regardless of the network exit IP.
  2. Check the proxy address
    Extracts the domain from ANTHROPIC_BASE_URL and compares it with 147 built-in domains; the list is base64-encoded and then XOR-obfuscated with key 91.
  3. Rewrite the date line
    Replaces the apostrophe in “Today's date is …” with one of three look-alike Unicode characters, and swaps the date hyphens for slashes when the time zone matches.
  4. Read on the server side
    Together the two changes form a 2 to 3 bit classification tag, so the server can tell whether a request comes from a mainland China time zone just by inspecting the characters.

Points of contention

  1. The technique is steganography: the signal hides in normal-looking text that editors and terminals render identically
  2. The author argues it conflicts with transparency rules on data collection such as GDPR and App Store guidelines
  3. Claude Code can read and write code, run commands and operate Git, so a hidden marker raises the stakes for trust
  4. The post drew strong reactions from developers in China and abroad, and the debate has moved beyond Chinese users
